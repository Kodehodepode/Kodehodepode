## Notater

Forklaringer/eksperimenter rundt undervisningen.

* [Booleans in if-tests](https://github.com/Kodehodepode/random-notes/blob/main/booleans-in-if-tests.js)

  Oppsummering: `if (uttrykk === true)` er ikke nødvendig, da holder det med `if (uttrykk)`

* [List XOR](https://github.com/Kodehodepode/random-notes/blob/main/list-xor.js)

  Eksempler på hvordan lage en liste med bare unike elementer, fra to andre lister.

* [Math.random()](https://github.com/Kodehodepode/random-notes/blob/main/math-random.js)

  Oppsummering: `Math.floor(Math.random() * 10) + 1` med + 1 for å unngå 0 og inkludere 10.

* [Post/pre increment](https://github.com/Kodehodepode/random-notes/blob/main/post-pre-increment.js)

  Demonstrasjon av forskjellen på `++i` og `i++`.

* [Random but unique](https://github.com/Kodehodepode/random-notes/blob/main/random-but-unique.js)

  Løsninger på hvordan man velger mer enn ett tilfeldig element fra en liste, uten å få samme elementet to ganger.

* [Throw or return Error](https://github.com/Kodehodepode/random-notes/blob/main/throw-or-return-error.md)

  Kort guide til når tid man bør bruke `throw` og når man bare bør returnere et `Error`-objekt.
